# Birthday Calendar

这是一个基于 Vite + React 的生日日历项目。

## 环境要求

- Node.js 18 或更高版本
- npm

## 安装依赖

首次运行项目时，在项目根目录执行：

```bash
npm install
```

## 启动开发环境

安装依赖后执行：

```bash
npm run dev
```

启动成功后，终端会显示本地访问地址，通常是：

```text
http://localhost:5173
```

在浏览器中打开该地址即可查看项目。

## 构建生产版本

```bash
npm run build
```

## 本地预览生产构建

```bash
npm run preview
```
